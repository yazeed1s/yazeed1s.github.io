zwm

2023–Present · Active

Tiling window manager for X11, written in C with XCB. Uses a BSP tree for layouts, master/stack/grid modes, per-monitor workspaces, and drag-and-drop. Runs at around 2 MB.

Prism

2025–Present · Active

Live streaming engine in Go, one binary. Pipeline is ingest, demux, normalize, transcode, transmux, sinks, origin, each stage its own package. Codec parsing (H.264, H.265, AAC, Opus, AV1, VP9) and format muxing (fMP4, HLS, MPEG-TS) are in-house, no third-party media library gets past those boundaries. Takes RTMP or SRT in, serves HLS/LL-HLS out.

rtmp

2025–Present · Active

RTMP ingest library for Go, zero dependencies outside stdlib. Handles the handshake, chunk parsing, AMF0 commands, and flow control, then hands off typed media packets through five callbacks. What you do with those packets, decoding, muxing, storage, is left entirely to the caller. Powers ingest in Prism.

  • #Go
  • #RTMP
  • #Streaming
  • #Library

Strimo

2024–Present · Active

Streaming platform. Modular monolith in Go, CQRS split between write handlers and read DTOs, stream engine is mostly in-house. Outbox/inbox around NATS gives exactly-once delivery, so state changes and events stay atomic. WebSocket for chat, SSE for stream runtime and notifications, PostgreSQL and Redis underneath, SvelteKit frontend.

oflv

2026 · Archived

Small FLV parser, written in Odin mostly to try the language out. Walks the file header and tag stream, validates each tag against its PreviousTagSize, and picks apart AVC video payloads down to the SPS/PPS in the AVCDecoderConfigurationRecord. Has an ffmpeg helper to generate test files on the fly.
